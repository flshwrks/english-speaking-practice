## デザインの方針
- **トーン**: 明るいオフホワイトの背景に、鮮やかなインディゴ（主色）＋コーラル（アクセント）＋ミント（成功）＋サンフラワー（注意）。角丸を大きく（16〜28px）、柔らかい影、ところどころに有機的な形（ブロブ）
- **文字**: 英文は Plus Jakarta Sans、和文は Zen Maru Gothic（丸ゴシックで親しみ）。数字は tabular
- **マスコット**: 吹き出しの形をしたキャラクター「Toki（トキ）」。表情違い（通常・考え中・喜び・応援）を SVG コンポーネントで
- **イラスト**: シナリオごとのアイコン（会議・握手・プレゼン・コーヒー・電球など）を SVG で統一タッチに。空状態・ログイン・分析中にも
- **アプリの骨格**: PC は上部ナビ、スマホは下部タブバー（ホーム/カリキュラム/表現/成長/プロフィール）
- **ダークモード**: 同じ色相から段階を選び直して対応
- **動き**: ボタンの押下、カードのホバー、分析中のマスコット、会話中の音量メーター。`prefers-reduced-motion` を尊重
