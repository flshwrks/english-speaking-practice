# 2026-09-28 学習者モデル（学習者像）の蓄積

## 対象
- src/db/schema.ts（profile.learner_model 列と LearnerModel 型を追加。`npm run db:push` 済み）
- src/lib/analysis.ts（分析の入力に学習者モデルを渡し、出力で更新版を受け取って保存）
- src/lib/lesson.ts（ProfilePatch に learnerModel）
- scripts/review-export.ts（週次レビューの資料に学習者モデルを載せる）

## 変更内容
- 人物像・強み・弱点・苦手な音（各最大6）とセッション数を profile に1つだけ持つ
- 会話後の分析で、既存モデルを背景知識として渡し（FB の優先度や説明を本人の癖に合わせる。モデルには言及させない）、同じ呼び出しで更新版を返させて上書き保存。形が崩れていたら更新だけ見送る
- 会話 AI・FB 画面には専用の項目を設けない（背景知識としてだけ使う）
- 初期版は過去の実セッション（#1, #16）から一度だけ生成して保存

## 理由
- FB の弱点・強みが次回以降に生かされておらず、本人に合わせた FB にするため

## 残作業
- 会話 AI にも背景知識として渡すかは、様子を見て判断（現状は FB のみ）
